## 中文

**ColaMD 是一个免费、优雅的 Markdown 编辑器：打开就是你的文字和文件列表，没有工具栏，文件永远在你自己电脑上，写到哪存到哪。**

最新一版加了标签页，解决的是一件很具体的事。

写周报要翻上个月的记录，以前得来回开文件。现在在文件列表里按住 `⌘` 点一下，它就在新标签里打开，两份都在。每个标签记得自己写到哪、读到哪，切回去就是你离开时的样子；不需要了就中键点掉。只开一份文档的时候，标签栏根本不出现，界面和你熟悉的一模一样。

顺手还把它擦干净了：选中标签上那根彩色细线去掉了。ColaMD 是一块画布，标签栏不该抢戏。

## English

**ColaMD is a free, elegant Markdown editor: you open it and see your text and a file list, no toolbar, and your files stay on your own computer, saved as you write.**

The latest release adds tabs, and it solves one very concrete problem.

You are writing a report and want to check last month's notes. Hold `⌘` and click that file in the list on the left: it opens in a new tab, both stay put, neither gets in the way. Each tab remembers where you were, so switching back feels like you never left. Done with one? Middle-click it. With a single document open, the tab strip does not appear at all and the window stays the way you know it.

While we were in there, the colour line on the active tab went away. ColaMD is a canvas, and the tab strip should not be the thing you notice.
