# ColaMD 2.1 系列 · 社会媒体公告（综合一条）

## 中文

**ColaMD 2.1 系列已全部发布。这一系列只做了一件事：给编辑器加上标签页，然后把外壳一层层减掉。**

### 先是标签页（2.1.0）

同一个窗口里可以同时开好几份文档。每个标签自己带着内容、撤销历史、未保存状态和阅读位置，来回切换互不影响。

怎么开：`⌘T`，或者 File 菜单里的「新建标签页」；在文件列表里 **⌘ 加点击**（Windows / Linux 上是 Ctrl）一个文件，它会在新标签里打开；右键文件，第一项也是「在新标签页打开」。
怎么关：中键点标签，或者 `⌘W`。

边界也说清楚：标签页用完即走。只有一个文档时标签栏根本不出现，界面和你熟悉的样子完全一样；关掉应用不会记住这组标签，也没有固定标签、标签分组、跨窗口拖拽这类工作区功能。我们不想让它变成一个需要打理的项目。

### 然后是手感（2.1.1）

新建标签页的加号回到标签栏右端，紧跟最后一个标签。标签上右键有菜单：关闭、关闭其他、关闭右侧，以及复制路径和在文件管理器中显示。鼠标停在标签上一秒后才出现提示，而且只显示 `⌘W`，不打扰你。

### 最后是做减法（2.1.2）

第一个标签贴住窗口左边缘；选中标签上那根会挑主题色的细线去掉了。选中状态靠纸张色和底边开口表达，已经够了。

ColaMD 是一块沉浸式的画布，标签栏只是薄薄一层壳。这个系列从头到尾都在把壳减到最少。

## English

**The ColaMD 2.1 series is out. It did one thing: give the editor tabs, then take the shell away again, layer by layer.**

### First, tabs (2.1.0)

Several documents in one window. Each tab keeps its own content, undo history, unsaved state and scroll position, and switching between them changes nothing else.

How to open one: `⌘T`, or New Tab in the File menu; **⌘-click** a file in the file list (Ctrl on Windows and Linux), or right-click it and pick Open in New Tab.
How to close one: middle-click the tab, or `⌘W`.

The limits too: tabs are for right now. With a single document the tab strip never appears, so the window looks exactly the way you are used to, and the app does not remember the set after you quit. No pinned tabs, no tab groups, no dragging tabs between windows. We did not want a workspace you have to tend.

### Then, the feel (2.1.1)

The new-tab plus sits at the end of the strip, right after the last tab. Tabs have a right-click menu: close, close others, close to the right, copy path, reveal in your file manager. Hovering a tab waits a second before it says anything, and then only shows `⌘W`.

### Finally, subtraction (2.1.2)

The first tab now sits flush with the window edge, and the theme colour line on the active tab is gone. The paper colour and the open bottom edge already say which tab is active.

ColaMD is an immersive canvas, and the tab strip is a thin shell around it. This whole series was spent making that shell thinner.
