# ColaMD 2.1 系列 · 社会媒体公告（场景版）

## 中文

**一个窗口，装得下你正在写的每一份文档。**

写周报的时候想翻上个月的记录对照一下，以前得来回开文件。现在在左边文件列表里按住 `⌘` 点一下那个文件，它就在新标签里打开，两份都在，互不打扰。Windows 和 Linux 上是 Ctrl。

每个标签都记得自己的位置：写了什么、改到哪一步、还没保存、读到哪儿。切回去，就是你离开时的样子。

不需要了就中键点掉，或者按 `⌘W`。只开着一份文档的时候，标签栏根本不会出现，界面和你熟悉的样子一模一样。标签页不会记住上次开了哪些，也没有分组，它只在你需要对照几份文档的时候帮上忙，用完就走。

顺带把外壳又擦干净了一点：第一个标签贴住窗口的边缘，选中标签上那根彩色细线也去掉了。ColaMD 是一块沉浸式的画布，标签栏不该抢戏。

免费、开源，文件永远在你自己电脑上。macOS、Windows、Linux 都能用。已经在用的朋友，应用内会提示更新：

Apple 芯片（M 系列）：https://github.com/marswaveai/ColaMD/releases/download/v2.1.2/ColaMD-2.1.2-arm64.dmg
Intel 芯片（旧款 Mac）：https://github.com/marswaveai/ColaMD/releases/download/v2.1.2/ColaMD-2.1.2-x64.dmg
Windows 与 Linux：https://github.com/marswaveai/ColaMD/releases/tag/v2.1.2

还不想装？先打开 colamd.com，首页那块就是真的编辑器，能打字、能换主题。

## English

**One window, holding every document you are working on.**

You are writing a report and want to check last month's notes. You used to close one file and open the other. Now hold `⌘` (Ctrl on Windows and Linux) and click that file in the list on the left. It opens in a new tab, both stay put, and neither one gets in the way.

Each tab remembers where it was: what you wrote, what you undid, what you have not saved yet, how far down you had read. Switch back and it is exactly as you left it.

Done with one? Middle-click it, or press `⌘W`. When you only have a single document open, the tab strip does not appear at all, so the window looks the way you already know. Tabs do not remember last session's set and they do not group; they are there for the moment you need two documents side by side, and they get out of the way after.

While we were in there, the shell got a little quieter: the first tab now sits flush with the window edge, and the colour line on the active tab is gone. ColaMD is an immersive canvas, and the tab strip should not be the thing you notice.

Free, open source, your files stay on your own computer, on macOS, Windows and Linux. Already using it? The app will offer the update:

Apple silicon: https://github.com/marswaveai/ColaMD/releases/download/v2.1.2/ColaMD-2.1.2-arm64.dmg
Intel Macs: https://github.com/marswaveai/ColaMD/releases/download/v2.1.2/ColaMD-2.1.2-x64.dmg
Windows and Linux: https://github.com/marswaveai/ColaMD/releases/tag/v2.1.2

Not ready to install? Open colamd.com. The block on the home page is the real editor, ready to type in.
