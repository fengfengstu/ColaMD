# ColaMD v2.1.0 Social Copy

## Chinese

ColaMD 2.1.0 已发布，这一版的主角是**标签页**。

- **标签页**：一个窗口里可以同时开多个文档。`⌘T`、File 菜单的「新建标签页」、或者在文件面板里右键选「在新标签页打开」都能开一个。点击切换，中键或 `⌘W` 关闭
- **每个标签是自己的一份**：内容、未保存状态、撤销历史、滚动位置都按标签分别保存，来回切换互不影响。切走时不会把没保存的内容写盘，也不会弄丢，只在真的会被丢弃时（关标签、关窗口）才问你
- **修掉一个严重问题**：之前在一个新开的、还没命名过的标签里保存，内容会被写进上一个标签的那个文件，连带把自己的名字也改过去。现在每次保存都会声明这份内容属于哪个文档，主进程严格核对，对不上就拒绝写入
- **正文空白处点得出光标**：短文档下方以前点不出光标，切换标签后光标还会消失，现在整个正文区都能落光标，切回来自动回到正文
- **新标签页不再有多余的滚动条**：空文档本来没什么可滚，却因为正文高度算错而出现滚动条，现在没有了
- **菜单更干净**：File 菜单的「最近打开」不再带着系统的时钟图标，也不再是英文

免费、开源、本地优先，支持 macOS、Windows 与 Linux。应用内会自动提示更新，也可以直接下载：

## English

ColaMD 2.1.0 is out, and the headline is **tabs**.

- **Tabs**: keep several documents open in one window. Create one with `⌘T`, File → New Tab, or by right-clicking a file in the panel and choosing Open in New Tab. Click to switch, middle-click or `⌘W` to close
- **Each tab is its own document**: content, unsaved state, undo history and scroll position are kept per tab, and switching never mixes them. Leaving a tab does not write anything to disk on your behalf and does not drop what you typed
- **A serious bug fixed**: saving in a new, never-named tab used to write its content into the previous tab's file and rename the tab after it. Every save now states which document it belongs to, and the main process refuses to write when that does not match
- **Caret clicks below the text**: clicking under a short document used to place no caret, and the caret vanished after switching tabs. The whole page area accepts the caret now, and switching back puts it back in the document
- **No stray scrollbar on a new tab**: an empty document no longer shows a scrollbar because its height was computed wrong
- **A cleaner File menu**: Open Recent no longer carries the system clock icon, or an English-only label
